# Дипломный проект. Автотесты UI и API тестирование

## Стек используемых технологий
- Python 3$
- pytest;
- Selenium (для UI);
- Requests (для API);
- allure-pytest для создания отчетов;
- GitHub.

## Структура проекта
- ./test* - папки с тестами;
- ./pages - описание страниц.

## Шаги по работе с проектом
1. Склонировать проект 'git clone https://github.com/VitalScher/Diplom.git';
2. Установить необходимые для работы библиотеки:
- pip install selenium
- pip install pytest
- pip install requests
- pip install allure-pytest
3. Запустить тесты 'pytest'.
