# Дипломный проект. Автотесты FT и API тестирование

## Стек используемых технологий
- Python 3;
- pytest;
- Selenium (для UI);
- Requests (для API);
- allure-pytest для создания отчетов;
- GitHub.

## Структура проекта
- ./test* - папки с тестами;
- ./pages - описание страниц.

## Шаги по работе с проектом
1. Склонировать проект 'git clone https://github.com/VitalScher/Diplom.git';
2. Установить необходимые для работы библиотеки:
- pip install selenium
- pip install pytest
- pip install requests
- pip install allure-pytest
3. Запустить тесты 'pytest'.

    python -m pytest --alluredir allure-result
4. Сформировать отчет Allure.

    allure serve allure-resul

## Описание тестов
### Объект тестирования
Цель тестирования является веб-приложения YouGile. 

### Функциональные тест-кейсы №№01-05
Тест-кейсы охватывают функции блока Сотрудники 
Тест-кейсы выполнены независимыми друг от друга. Все необходимые данные создаются в ходе выполнения теста и удаляются после его окончания. 
Исходные данные подгружаются через фикстуры из conftest.py.

### API тест-кейсы №№06-14
Тест-кейсы охватывают функции блоков Проекты и Отделы.
Тест-кейсы выполняются последовательно. Следующие тесты работают с объектами созданными в предыдущих кейсах. Часть данных вводится в ручную в теле тестов.
